# TÜGVA Yaz Okulu Kayıt Sistemi

Modern, Firebase tabanlı kayıt ve QR Check-in sistemi.

## Özellikler

- Online kayıt
- QR Kod oluşturma
- PDF kayıt kartı
- Yönetici paneli
- QR Check-in
- Excel'e aktarma
- Mobil uyum
- Firebase Firestore
- Firebase Authentication

## Kurulum

1. Firebase projesi oluşturun.
2. Firestore'u etkinleştirin.
3. Authentication → Email/Password'u açın.
4. `js/firebase.js` dosyasına Firebase bilgilerinizi ekleyin.
5. GitHub Pages'i etkinleştirin.
